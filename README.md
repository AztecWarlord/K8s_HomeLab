My first Kubernetes home lab.

- **Storage:** 119 GB SSD

### Proxmox Host

- **Device:** Headless Dell OptiPlex 7050 Micro
- **CPU:** Intel Core i5-6500
- **Memory:** 16 GB DDR4 RAM
- **Storage:** 256 GB SSD
- **Operating system:** Proxmox VE installed on bare metal
